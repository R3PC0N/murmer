What's coming.

Murmur is being built to be the voice dictation tool you actually want to use.

Push-to-talk

Hold any configurable key to record. Release to transcribe and paste instantly into whatever app is focused.

🔒

Your audio stays yours

Transcription runs on your own hardware using OpenAI Whisper. Nothing leaves your machine unless you choose it.

✨

AI cleanup

An optional AI pass removes filler words, fixes punctuation, and preserves your language and tone.

🌐

Remote transcription

Offload heavy lifting to a more powerful machine — on your network or via a hosted endpoint.

🐧

Windows & Linux

First-class support for Windows 10/11 and major Linux distributions. One installer, no fuss.

⚡

No subscription required

Run it locally for free, forever. A hosted option will be available for those who want it — never forced.
