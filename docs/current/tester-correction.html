Small correction on Python versions

In my previous email I mentioned that Python 3.12 and 3.13 are not compatible with Murmur. That turns out to be incorrect — I've since tested both versions and everything works fine.

What this means for you
  • Already have Python 3.12 or 3.13? No need to install 3.11 — just run the Murmur installer directly.
  • No Python installed yet? Python 3.10–3.13 all work. Python 3.11 is still a safe choice. ⚠ Python 3.14 (currently the latest on python.org) is not yet compatible — please pick 3.13 or lower.
  • Already installed Python 3.11? Nothing to change — that still works perfectly.

Sorry for any confusion. The installer itself has been updated as well, so it no longer rejects newer Python versions. If you haven't installed yet, grab the latest version below.
