You're invited to test Murmur

I'm building Murmur — a voice dictation app for Android that transcribes your speech and pastes it directly into whatever you're typing. No cloud subscription, no lock-in: you point it at your own Whisper server and that's it.

What to try
  • Set your Whisper server URL in Settings
  • Hold the mic button to record, release to transcribe
  • Try dictating into different apps (WhatsApp, browser, notes)
  • Enable AI Cleanup if you have an Anthropic API key

Tap the button below on your Android device to join the test and install the app via Google Play:
