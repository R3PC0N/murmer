Windows

On iOS or just prefer a desktop experience? Murmur runs on Windows too — install in this order:

  1. Python 3.10–3.13 - required. Python 3.11 is recommended if you don't have Python yet. ⚠ Python 3.14 (currently the latest on python.org) is not yet compatible. Make sure to tick "Add Python to PATH" during installation.
  2. Murmur v1.2 - run the installer after Python is set up.
  3. CUDA drivers (optional) - only needed if you have an NVIDIA GPU and want faster transcription.
