You're invited to test Murmur

I'm building Murmur — a voice dictation app that transcribes your speech and pastes it directly into whatever you're typing. No cloud subscription, no lock-in: you point it at your own Whisper server and that's it.

Available now: Linux & Android & Windows  ·  In development: iOS

Linux

Install the system prerequisites for your distribution first, then run the command below. It downloads Murmur and runs the portable, non-root bootstrap for the Python environment and desktop launcher.

Run in a terminal

curl -sSL https://murmurlabs.dev/downloads/murmur-install.sh | bash
  • Installs to ~/murmur — start it with ~/murmur/murmur.sh
  • Tested on Arch Linux / Omarchy with Hyprland and native Wayland; Debian and Ubuntu prerequisite packages are documented in the included README
  • Requires Python 3.10 or newer; Python 3.14.6 is confirmed working on the tested Arch workstation
  • CPU and CUDA transcription are supported. The built-in default configuration falls back to CPU automatically when CUDA is unavailable

The bootstrap does not install system packages or change input-device permissions. Hyprland hotkeys use temporary compositor bindings; X11 uses its separate compatibility backend. Other native-Wayland compositors do not yet have a supported global-hotkey backend.

Arch/Omarchy users need the GTK3, WebKitGTK, PyGObject/Cairo, PortAudio/PipeWire, AppIndicator, wtype, and XDG packages listed in the README; Hyprland supplies hyprctl. Debian/Ubuntu use their separately listed package equivalents. X11 testers need xdotool instead of the Wayland input tools.

Windows

Murmur is also available on Windows. Install Python first, then run the Murmur installer. Make sure to tick "Add Python to PATH" during the Python installation.

The current Windows installer accepts Python 3.10–3.13. Python 3.14.6 compatibility is confirmed for the tested Arch/Linux environment.

What to try
  • Set your Whisper server URL and API key in Settings
  • Linux / Windows: hold the hotkey (default: F9) anywhere to record — release to transcribe and paste
  • Try Automatic, Dutch, and English language selection in Transcription settings
  • Android: tap the floating overlay button when a keyboard is open — auto-pastes on completion
  • Try dictating into different apps (browser, notes, terminal, chat)
  • Enable AI Cleanup in Settings if you have an Anthropic API key — it removes filler words and fixes punctuation

Known Linux quirks
  • The tray icon needs a StatusNotifier/AppIndicator host. Waybar with its tray module is validated; GNOME commonly needs an AppIndicator extension
  • Native Wayland push-to-talk currently supports Hyprland specifically. Murmur detects conflicting Hyprland F-key bindings and lets you choose another available key
  • Wayland text insertion uses wtype; X11 uses xdotool
  • On first launch Murmur downloads the Whisper model (~1.5 GB for the default), which takes a few minutes depending on your connection
