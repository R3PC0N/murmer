Get started in minutes.

🪟 Windows

1. Install Python 3.10+ from python.org
   Tick "Add Python to PATH" during setup
2. Download and run Murmur-Setup-vX.X.exe
3. Add your Anthropic API key to .env
   (optional — AI cleanup only)
4. Hold F9 anywhere and start dictating
↓  Download latest Python installer

🐧 Linux — Ubuntu / Debian / Zorin OS

git clone https://github.com/R3PC0N/murmur.git
cd murmur
bash setup_linux.sh
./murmur.sh

The setup script installs all system packages, creates a virtual environment, and enables the AppIndicator extension for the system tray. Log out once after setup for the global hotkey to take effect.
